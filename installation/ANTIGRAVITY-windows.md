# Antigravity on Windows

The plugin is pinned to Antigravity **1.107.0**, which is released as 1.23.2.

1. Download the one for your machine. Almost every Windows laptop is x64. ARM64 is only
   for a Snapdragon or Surface Pro X.
   - [Windows x64](https://edgedl.me.gvt1.com/edgedl/release2/j0qc3/antigravity/stable/1.23.2-4781536860569600/windows-x64/Antigravity.exe) (208 MB)
   - [Windows ARM64](https://edgedl.me.gvt1.com/edgedl/release2/j0qc3/antigravity/stable/1.23.2-4781536860569600/windows-arm64/Antigravity.exe)
2. Double-click the .exe and follow the installer.
3. Open Antigravity from the start menu.
4. Check the version: command palette (ctrl + shift + p), "About". It must say **1.107.0**.

## Turn off automatic updates

Do this before the event. Antigravity updates itself, and a newer version will not match
the plugin.

Command palette, "Preferences: Open Settings (UI)", search for **update mode**, set it to
**none**. Then quit and reopen Antigravity.
