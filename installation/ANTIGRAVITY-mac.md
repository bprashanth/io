# Antigravity on macOS

The plugin is pinned to Antigravity **1.107.0**, which is released as 1.23.2.

1. Download the one for your Mac. If you are not sure which, click the apple menu, About
   This Mac: an M1/M2/M3/M4 is Apple Silicon, anything saying Intel is Intel.
   - [Apple Silicon](https://edgedl.me.gvt1.com/edgedl/release2/j0qc3/antigravity/stable/1.23.2-4781536860569600/darwin-arm/Antigravity.dmg) (187 MB)
   - [Intel](https://edgedl.me.gvt1.com/edgedl/release2/j0qc3/antigravity/stable/1.23.2-4781536860569600/darwin-x64/Antigravity.dmg) (195 MB)
2. Double-click the .dmg, then drag Antigravity into Applications.
3. Open it from Applications.
4. Check the version: in Antigravity, the command palette (cmd + shift + p), "About".
   It must say **1.107.0**.

## Turn off automatic updates

Do this before the event. Antigravity updates itself, and a newer version will not match
the plugin.

Command palette, "Preferences: Open Settings (UI)", search for **update mode**, set it to
**none**. Then quit and reopen Antigravity.

## Then

Install the privacy shield: back to the [README](../README.md#a-the-privacy-shield-in-antigravity).
