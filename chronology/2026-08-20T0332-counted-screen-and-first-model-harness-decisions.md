# Counted screen closes; 9B stops for futility and a harness path emerges

The frozen five-case screen completed for default Antigravity 1.1.15 and Cline
3.0.55 with `qwen/qwen3.8-27b:nitro` at controlled xhigh effort. Antigravity
scored 261/500 and Qwen/Cline 339/500. Both had critical failures in three of
five cases, so the 15.6-point Qwen lead is a relative screen pass but not an
absolute-readiness result.

Visual inspection changed the interpretation materially. Antigravity's
polished Census page used unrelated 1961 catalog records as citations, and its
programme page was polished but blank and based on invented data. Qwen's PDF
page was strong, while its programme page used the wrong employment
denominator and leaked raw CSS. The counted Qwen Census run ended before a page
after an Alibaba moderation message surfaced inside an HTTP-200 stream.

An excluded Census retry cannot replace that zero, but it established
conditional capability. Qwen found official Census catalog 42557, exact values
and a valid workbook download, scoring 85. It also took 52 calls and 1,519
provider-seconds, omitted the exact difference from the page, produced a
malformed CSV header and overflowed a phone viewport by 103 px. The citation
checker was corrected to recognize catalog 42557 after independently verifying
its title and direct workbook response.

The default-Cline Qwen 3.5 9B track then met both frozen futility triggers after
the minimum three pairs. It scored 41/300 versus Antigravity's 183/300, a
47.3-point mean gap, and had three critical application failures versus one.
It produced no website in the programme, CSV or Excel case, so PDF and web
discovery were not run.

The first valid DeepSeek Harness diagnostic changed the harness outlook. With
the same 27B model, native High effort and the generic NGO guardrail, it scored
92 on the programme case. It showed both ambiguous employment definitions,
gave the required 14 pp and 19 pp comparisons, refused causal guessing and
delivered the exact CSV in 328 seconds. It still made 35 calls and did not put
the last district-specific follow-ups back into the final page. The published
Python composition also used danger-full-access and read outside the staged
workspace, so it must be containerized before further benchmark use.
