# V1 remote gateway and non-gating local diagnostic

Owner authorized a separate V1 experiment: every user executes remotely while local synthetic
capability reports inform V2. Main IO consolidation is deferred. Expanded design:
[proposal](../proposals/v1-remote-runtime-local-diagnostic.md).

## Measured here

Evidence: [run directory](../benchmarks/runs/2026-09-27-v1-gateway/README.md).
39 Docker/gateway integration checks and 19 lifecycle/isolation checks passed on Linux arm64.
The same signed identity reconnects to the same opaque workspace; a second identity cannot
read, upload, stream, delete or proxy the first workspace. No worker has published host ports.
Files/state persist across restart and complete container recreation. Delete removes only the
selected runtime/network/volumes. A fixed operator-started web service is fetched through the
authorized gateway as an attachment. Codex's inner sandbox denies reads of controller state;
Docker network separation denies A→B raw TCP, with B→B as a positive control.

The local full diagnostic passed 17/17 on the DGX and still reported `executionMode: remote`.
Actual Electron tests passed browser OAuth startup through the gateway, cancellation, copy
attachment/download, unchanged local source, fixed-port download and report display; screenshots
were opened and inspected. The Browser plugin had no available browser, so existing Playwright
Electron tooling was used. No renderer errors were observed.

Public `https://io.idli.cc` redirects to Cloudflare Access and its email-code login page renders
in the isolated sign-in window. Initial HTTP 403 was the ambient outbound proxy; a direct
HTTPS request succeeds. Team `t4gc.cloudflareaccess.com` and application audience were discovered
from the redirect metadata and that metadata's signature was verified against the team's keys.
An unsigned email header is not identity. The production-configured gateway refuses absent
assertions and signed non-app metadata. No tunnel token or Cloudflare admin credential was read.

## Implementation

FastAPI gateway validates RS256/issuer/audience/expiry/human subject and maps issuer+subject to
one SQLite workspace. Private worker capability/IP/container names never reach the client.
Persistent per-user volumes replace ephemeral tmpfs only in explicit V1 mode; old mode remains
compatible. One active Codex terminal, several saved conversation IDs; new conversations share
files. SSE ends at Access expiry. Signed local fixtures have no production CLI bypass.

Separate launcher `app/io/gateway/run.sh` opens Cloudflare sign-in, then the existing remote
terminal UI with conversation/diagnostic controls. ChatGPT still uses the existing system-browser
OAuth callback relay, without enabling device codes. The diagnostic uses the actual 17-property
runner and no model calls; missing runtime/control results are INCONCLUSIVE, never PASS. It
runs independently of remote startup and stores evidence only on the laptop.

Pinned Codex stays 0.154.0. Persistent storage remains experimental: no volume quota/backups,
existing nested-bwrap seccomp/AppArmor exceptions, no arbitrary HTML on the gateway auth origin.
A worker network namespace started by Offline Codex is not automatically a reachable live app.

Lower-model Cursor CLI (`gpt-5.4-mini-high`) implemented worker helpers, diagnostic scaffolding,
and gateway tests/review. Parent review corrected real Codex's nested session metadata schema,
prevented stale diagnostic results, and replaced an unbounded lifecycle lock table. Unit coverage
includes expiry-bounded streams, forged tokens/wrong issuer/audience, ownership and spoofed email.

## Deployment boundary and remaining tests

The old 8787 worker is still signed in and has a running Codex terminal; it was left untouched.
A user service `io-v1-gateway.service` runs the new production configuration on loopback 8789.
The owner was asked to change the Cloudflare destination to localhost:8789 (or explicitly choose
migration of the old session). Local synthetic tests used 8788, never the public tunnel.

Not tested: completed human Cloudflare authorization, a fresh authorized Codex model turn and
resume through this gateway, actual Windows/macOS laptops, or public live-app rendering.
Prior confirmed browser OAuth/model interaction remains baseline evidence, not proof that the
new authenticated path completed. The next human test is in the gateway README. Main IO interface
integration and the other security surfaces remain deferred.

Validation before initial commit: 11 gateway unit tests, 3 conversation helper tests, 7 diagnostic
cases, 8 remote transport/browser-relay groups, 19 launcher checks and 34 proxy tests passed.
