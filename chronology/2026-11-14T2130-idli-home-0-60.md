# 2026-11-14, 21:30 IST — The stripped-down "0-60" flow works end to end

The owner cut Drivey down to one path:
- search files and ask;
- the redaction review in Idli's pane (no model);
- the person's own Claude Code CLI on the right;
- charts in Idli's pane, clickable back to Claude;
- save a Mini that a small model can answer.

Cleaning, forms and teaching are out of this path. The code stays.

## Built
- **Codex** (worktree io-idli-home; 30 tests including a headless browser):
  - Idli home `/home`: search with chips and @, the review, Send;
  - `lib/idli_mcp.py`: `idli_show` and `idli_save_mini`;
  - `/view` (clickable chart);
  - `/mini` (questions with options; the 9B maps a typed question to one, word match as fallback).
- **Mine:**
  - Claude runs as a **terminal** (the real CLI, like the Claude Code workspace), not Paseo's chat view.
  - Paseo **P17** (builds idli8–idli11, installed by reloading the window, no restart): `window.__idliPlaceTab` puts a
    chat, terminal or browser tab on a side with focus, opening a terminal's tab when it has none.
  - `uiswitch` drives the window through DevTools instead of a second app launch. The second launch had left a second
    Paseo window open, and the pane never moved.
- **Fixes found on the laptop:**
  - `--mcp-config` swallowed the prompt;
  - the proxy's final check scanned Claude Code's own tool text, where "pip" and "Mine" matched masked
    species/Toda-name values and blocked every request; it now checks the system prompt and messages only, and logs
    which codes, never the values;
  - Claude's folder-trust question is pre-answered for its own folder;
  - charts open in Idli's pane (the home page watches for them) instead of via Paseo browser calls;
  - focus goes back to Claude after a chart question;
  - the installer moves old builds aside rather than deleting them.

## Tested on the laptop (owner's real households file, Claude Pro subscription)
1. **Idli home (left):** searched "households", asked "Which ward has the highest average debt, and which households
   drive it?", reviewed the masked columns, and pressed Send.
2. **Claude CLI (right):** answered with real names (Yerawada highest; Nandini Chavan and Mohit Jadhav owe about 13

   answered with the six households, Rs 4,90,000 ÷ 6 = Rs 81,667.

   "Household debt".

   picked the right question with Kasewadi and 6 months. Run: none of Kasewadi's 6 households do (correct).
