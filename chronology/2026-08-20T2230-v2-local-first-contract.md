# V2 local-first execution contract frozen

The v2 brief was rewritten before implementation so a fresh agent can reuse the first-phase evidence instead of repeating it. It names the exact benchmark, architecture, critic, LoRA, setup and Antigravity findings that must be read first, plus the existing plan schema, runners, cases, oracles and result records.

The new primary model policy follows the event decision: a 2B--9B laptop-sized query/plan compiler is attempted first; detected failures escalate to Qwen 3.8 27B; a frontier model receives only an allowlisted value-free conversation/schema/structure/standard payload and never real rows, values, aggregates, results or screenshots. GPT-OSS 20B remains recorded diagnostic evidence but is not a v2 primary or finalist.

The 85% milestone is retained as standalone first-rung exact result-and-obligation accuracy after at most one constrained repair. Escalated success is reported separately. Critical silent errors remain a routed-system gate and cannot be hidden inside the 15%.

The contract explicitly prevents sector, place, case-ID and question-bank routing. It replaces bare text-to-SQL with the existing typed analysis-plan contract, treats SQL as a deterministic execution backend, requires untouched cross-subject/layout holdouts, and requires every counted page to be opened, exercised, screenshotted and personally inspected.

No model was downloaded or run in this checkpoint. The next step is to establish a pinned benchmark runtime, reproduce one preserved split run into a new directory and freeze the v2 compiler/routing suite before candidate screening.
