# Passing split smoke compared with Antigravity

The user clarified that the acceptance bar is Antigravity, not an imagined
perfect dashboard. The split path was therefore frozen after fixing only faults
that affected correctness, durable interaction, participant trust or a clear
visual mismatch with the baseline.

Qwen 3.8 27B at low effort compiled plans for the three smoke turns. DuckDB and
the fixed renderer produced every value and page. Turn 1 took 40.812 seconds.
Turn 2 needed one repair because the first plan did not include a named lowest
insight; both requests took 36.337 seconds. Turn 3 took 47.120 seconds. The four
OpenRouter requests totalled 124.269 seconds, USD 0.01540673, 4,308 prompt
tokens and 4,210 completion tokens, of which 1,632 were reasoning tokens.

The split-specific verifier passed the exact 2022/2023 percentages, durable
2023-only rows, Purnia at 76%, all three real-browser checks and the traceable
three-row download. Human review at 1440 by 1000 scored the page 8.8/10. It is
less elaborate than Antigravity's desktop page but is clear, finished, offline
and free of stale values, invented bands and unit errors.

Applying the existing weighted rubric diagnostically gives the split journey
95.3 versus the preserved Antigravity product smoke's 80.5. The 14.8-point gap
does not establish product equivalence: the split run did not test Windows
installation, IDE integration, arbitrary-file ingestion or concurrency, while
Antigravity is a complete installed coding product. It does establish that the
validated split architecture should advance to the ordinary CSV, XLSX, PDF,
official-web and safe-interpretation comparisons instead of spending more time
perfecting this one page.

The exact comparison, scope limits and evidence links are recorded in
`benchmarks/results/split-qwen38-27b-low-smoke-v1-development.json` and
`docs/split-pipeline-smoke-findings.md`.
