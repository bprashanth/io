# Generic layout and semantic-critic pair

The user challenged content-specific rules. Audit confirmed the first irregular-XLSX adapter named attendance, boys/girls and primary/secondary. It was replaced with geometry-based discovery using merged title bounds, two-row year headers, categorical row labels, numeric bodies, compatible category sets and exact ranges. It now produces the same expected columns for the earlier vertical workbook and a new horizontal mixed-unit workbook without sector-word branches. Unsupported merged layouts and multiple plausible rectangular sheets fail closed for a layout-selection fallback instead of silently choosing the largest sheet.

The rule-assisted English compiler is now a legacy ablation rather than the default. The default generic mode uses GPT-OSS 20B Low for the plan and a separate LLM critic for semantic completeness. Deterministic code owns only mechanics. The plan schema was corrected to permit zero transformation steps, because an all-row interactive dashboard is a valid no-op analysis.

On the new four-turn case, GPT-OSS as its own critic failed: it accepted a page that answered the 8 pp screening gap but omitted the 10-referral gap, and one critic call timed out at 120 seconds. Qwen 3.8 27B Low as critic passed but needed 141.572 recorded model seconds. The final counted run used Gemini 3.7 Flash Low only as a metadata-only semantic critic: five GPT-OSS planner calls, four critic calls, 35.259 model seconds and $0.004125425. Exact critic requests were retained and contain no raw rows, min/max summaries, enumerated values or hidden answers. Chromium, the independent oracle and human inspection passed; visual score 8.8.

The paired Antigravity run resolved to Gemini 3.7 Flash (High), completed four invocations in 267.386 seconds and parsed both tables exactly. Its rescued page scored 9.5 visually and its two-block Excel download is correct. Every turn nevertheless returned the same artifact-path permission ERROR. The page invented a 70% state target, omitted both cross-block gaps, left a Purnia card under the two-block filter, exported all three blocks to CSV and broke when external assets were blocked. Paired diagnostic scores are 98.8 split versus 81.5 Antigravity.

An audit after the successful run found two residual domain assumptions: a renderer hint said “district,” and rectangular-sheet scoring looked for district/block/state column names. Both were removed. The active path now uses dynamic dimension labels, geometry, shape and data types; ambiguous sheets fail closed for a general selector. The historical rule-assisted mode remains only to reproduce earlier ablations.

Because this development fixture was visible during extractor work, the result does not establish generalization. Code/prompt freeze followed by untouched cross-sector holdouts and systematic layout/paraphrase perturbations is the next gate.
