# Ordinary ANC CSV split run versus Antigravity

The first non-smoke split case used the five-turn ANC4 CSV conversation. A
first development run produced correct rows but failed to state the requested
+8 and +7 percentage-point changes. A durable-intent validator was added. In
the next run, turn 3 first omitted the change insight and was repaired; turn 4
first dropped the causal-limit card and was repaired; turn 5 needed both
repairs before preserving the prior analysis in the download page. This used
the allowed maximum of two automatic repairs on turn 5.

The counted run made nine Qwen 3.8 27B Low requests totalling 152.862 seconds,
USD 0.02293896, 12,876 prompt tokens and 6,307 completion tokens. All five pages
opened in Chromium with no console/page errors, external requests or desktop
overflow. The result rows match the independent oracle. The final page contains
the six Gaya/Nalanda rows for 2021--2023, visible +8 pp and +7 pp change cards,
the causal limitation and a matching source-bearing download.

One oracle expectation remains a noncritical shortfall: the chart and table
show Nalanda 80% versus Gaya 74% in 2023, but the page does not separately say
the gap is 6 pp. It was retained as a deduction rather than triggering another
development replay.

The preserved Antigravity CLI reference scored 84 and took 301.290 seconds. It
was visually richer, but its 2021 control errored, the durable page did not show
the +8/+7 pp result, its page download did not reflect the final comparison, it
invented thresholds, depended on external assets and overflowed narrowly by
821 px. Applying the same rubric gives the split run 95.5, an 11.5-point lead.
This is evidence for the split architecture on routine CSV work, not yet an IDE
or arbitrary-file equivalence result.
