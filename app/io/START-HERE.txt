io - what to do, depending on your computer
===========================================

Everything you need is on this drive. Nothing is downloaded, and you will never be
asked for an administrator password.

Find your computer below.


WINDOWS
-------
1. Open the folder  insightout\io\io-win-x64-offline
2. Copy that whole folder onto your computer, for example onto your Desktop.
   You can run it from this drive, but it is faster from your own disk.
3. Open the folder and double-click  io.exe
4. Windows will show a blue box saying it protected your PC. That is because io is
   not signed by a company Microsoft recognises, not because anything is wrong.
   Click  More info  then  Run anyway
5. io opens in a few seconds.


MAC WITH APPLE SILICON  (M1, M2, M3, M4)
----------------------------------------
Not sure? Apple menu, About This Mac. Anything saying M1 to M4 is Apple Silicon.

1. Double-click  insightout/io/io-mac-arm64-offline.dmg
2. Drag  io  out of the window that opens, into a folder of your own, such as your
   Desktop or your home folder. Do not put it in Applications.
3. RIGHT-CLICK io and choose Open, then Open again in the box that appears.
   A plain double-click will be blocked the first time. This is because io is not
   signed with an Apple account.
4. io opens in a few seconds. After this, a normal double-click works.


MAC WITH INTEL
--------------
1. Double-click  insightout/io/io-mac-x64.dmg
2. Drag  io  out into a folder of your own, such as your Desktop.
3. RIGHT-CLICK io and choose Open, then Open again.
4. The first start takes a few minutes and needs internet, because this version
   sets itself up. Later starts take about a second.
5. io will tell you that the private-data scanner cannot run on an Intel Mac. That
   is expected and it is not broken. Ask the organizers for the address of a
   privacy server and type it in, or choose to carry on without it.


LINUX
-----
1. Copy  insightout/io/io-linux-x64-offline  onto your computer, for example into
   your home folder. Copy it off the drive rather than running it from the drive.
2. Open a terminal in that folder and run:
       ./io
   Or, in your file manager, right-click io, Properties, Permissions, tick
   "Allow executing file as program", then double-click it.
3. io opens in a few seconds.


ONCE IO IS OPEN, ON ANY COMPUTER
--------------------------------
1. It asks for an API key or a server address. The organizers will give you this.
   It is kept in memory only and asked again next time you start io.
2. There are two optional boxes underneath. The organizers will tell you whether
   to fill them in.
3. Read the short note about your data and click OK.
4. Add a folder to work with. There is sample data on this drive at
   insightout/data if you would like something to try first.


IF SOMETHING GOES WRONG
-----------------------
Ask an organizer. It is far more likely to be a known quirk of one operating
system than a problem with your files, and your files are never sent anywhere
without being shown to you first.
