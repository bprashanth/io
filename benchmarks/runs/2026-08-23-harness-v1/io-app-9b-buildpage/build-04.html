The dashboard provides a snapshot of the current operational status, highlighting the total number of beneficiaries registered and the active stock of assistive devices. Key performance indicators track the overall inventory health and the count of individuals currently receiving support.

Finally, the coverage analysis cross-references device stock with beneficiary counts to estimate availability per disability category. This table highlights which device types might be insufficient to meet the demand of specific disability groups, guiding future procurement or distribution strategies.

How this was computed · 42 rows
WITH device_totals AS (SELECT "device_type", SUM(CASE WHEN "txn_type" = 'IN' THEN "qty" ELSE 0 END) - SUM(CASE WHEN "txn_type" = 'OUT' THEN "qty" ELSE 0 END) AS total FROM "device_inventory" GROUP BY 1), disability_counts AS (SELECT "Disability Type", COUNT(*) AS count FROM "beneficiary_master" GROUP BY 1) SELECT d."device_type", dc."Disability Type", dc.count, d.total, ROUND((dc.count * 100.0 / NULLIF(d.total, 0)), 2) AS coverage_pct FROM disability_counts dc CROSS JOIN device_totals d ORDER BY 1, 2
