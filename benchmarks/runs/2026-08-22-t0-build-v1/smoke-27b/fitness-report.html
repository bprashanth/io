Avg Sit-ups by Gender

How this was computed · 2 rows
SELECT b."Gender" AS gender, AVG(e."Sit ups") AS avg_sit_ups FROM baseline b JOIN endline e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC

Shuttle Run Speed Distribution

How this was computed · 2 rows
WITH stats AS (SELECT 'Baseline' AS stage, "Shuttle run sec" AS val FROM baseline UNION ALL SELECT 'Endline' AS stage, "Shuttle run sec" AS val FROM endline) SELECT stage, AVG(val) AS avg_time FROM stats GROUP BY 1 ORDER BY stage
