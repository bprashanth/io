The dashboard highlights the overall enrollment growth, with a total of 9,343 students in 2024. Girls outnumber boys by 4,893 students, indicating a gender balance trend. The enrollment line chart shows a steady rise from 8,813 in 2022 to 8,813 in 2024. Infrastructure gaps are evident: 25 toilets, 15 missing, and similar disparities in water and electricity access.

Girls vs Boys 2024

How this was computed · 2 rows
SELECT 'Girls' AS gender, SUM("Girls 2024") AS count FROM school_enrolment_by_year UNION ALL SELECT 'Boys', SUM("Boys 2024") FROM school_enrolment_by_year

Enrollment Trend 2022-2024

How this was computed · 3 rows
SELECT '2022' AS year, SUM("Girls 2022" + "Boys 2022") AS total FROM school_enrolment_by_year UNION ALL SELECT '2023', SUM("Girls 2023" + "Boys 2023") FROM school_enrolment_by_year UNION ALL SELECT '2024', SUM("Girls 2024" + "Boys 2024") FROM school_enrolment_by_year ORDER BY year

Infrastructure Availability

How this was computed · 3 rows
SELECT 'Toilets' AS item, SUM(CASE WHEN "Toilets functional (girls)"='Yes' THEN 1 ELSE 0 END) AS available, SUM(CASE WHEN "Toilets functional (girls)"='No' THEN 1 ELSE 0 END) AS missing FROM school_infrastructure UNION ALL SELECT 'Water', SUM(CASE WHEN "Drinking water"='Yes' THEN 1 ELSE 0 END), SUM(CASE WHEN "Drinking water"='No' THEN 1 ELSE 0 END) FROM school_infrastructure UNION ALL SELECT 'Electricity', SUM(CASE WHEN "Electricity"='Yes' THEN 1 ELSE 0 END), SUM(CASE WHEN "Electricity"='No' THEN 1 ELSE 0 END) FROM school_infrastructure
