The dashboard shows the total number of children at baseline (200) and at endline (200). The bar charts compare the average shuttle run time for girls and boys at each stage. A lower shuttle run time indicates better performance. By comparing the two bars for each gender, we can assess whether the improvement from baseline to endline is similar for girls and boys. If the reduction in shuttle run time is roughly the same for both genders, it suggests that they are improving equally. If one gender shows a larger improvement, that indicates a disparity in progress.

Baseline shuttle run by gender

How this was computed · 2 rows
SELECT "Gender" AS gender, AVG("Shuttle run sec") AS avg_shuttle FROM baseline GROUP BY 1 ORDER BY 2

How this was computed · 2 rows
