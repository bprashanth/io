A total of 200 children were evaluated across both baseline and endline assessments. Overall physical performance improved substantially, with an average increase of 2.92 sit-up repetitions and an average reduction in shuttle run time of 0.01 seconds.

Comparing outcomes across genders reveals how equitably physical stamina and speed developed. The detailed breakdown shows the baseline and endline progression for both sit-ups and agility shuttle runs.

Average Sit-ups Gain by Gender

How this was computed · 2 rows
SELECT b."Gender" AS gender, AVG(e."Sit ups" - b."Sit ups") AS avg_situp_gain FROM "baseline" b INNER JOIN "endline" e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC

Average Shuttle Run Time Reduction by Gender (Seconds Faster)

How this was computed · 2 rows
SELECT b."Gender" AS gender, AVG(b."Shuttle run sec" - e."Shuttle run sec") AS avg_time_reduction FROM "baseline" b INNER JOIN "endline" e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC
