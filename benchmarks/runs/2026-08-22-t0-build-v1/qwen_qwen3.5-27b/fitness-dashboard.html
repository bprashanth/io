This dashboard tracks the physical fitness progress of children from baseline to endline assessments. The total number of unique children tracked is 200. On average, children improved their shuttle run time by -0.01 seconds, indicating better speed and agility. Additionally, the average increase in sit-ups was 2.92 repetitions, showing enhanced core strength.

The bar chart by location highlights which areas saw the most significant improvements in shuttle run times, with the top performing locations leading the pack. Similarly, the coach-specific analysis reveals which instructors are driving the most substantial gains in core strength exercises.

How this was computed · 20 rows
SELECT b."Location", AVG(e."Shuttle run sec" - b."Shuttle run sec") AS avg_change FROM "baseline" b JOIN "endline" e ON b."Child ID" = e."Child ID" WHERE b."Shuttle run sec" IS NOT NULL AND e."Shuttle run sec" IS NOT NULL GROUP BY 1 ORDER BY 2 DESC LIMIT 20
