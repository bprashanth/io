Kids Improvement: Baseline to Endline

How performance metrics changed across locations and coaches

Total Children Tracked

This dashboard tracks the physical development of children from baseline to endline measurements. The first panel shows the total number of unique children tracked across both time points. Subsequent bar charts highlight average improvements in shuttle run times, sit-ups, weight, and height, grouped by location and coach. These metrics help identify which groups saw the most significant gains in agility, strength, and growth. The final tables list the top 10 locations and coaches for specific metrics like weight gain and height gain, allowing for a detailed comparison of performance across different training environments.

Avg Shuttle Run Improvement by Location

How this was computed · 20 rows
WITH baseline_agg AS (SELECT "Location", AVG("Shuttle run sec") AS b_run FROM "baseline" GROUP BY 1), endline_agg AS (SELECT "Location", AVG("Shuttle run sec") AS e_run FROM "endline" GROUP BY 1), combined AS (SELECT b."Location", b.b_run, e.e_run FROM baseline_agg b JOIN endline_agg e ON b."Location" = e."Location" WHERE b.b_run IS NOT NULL AND e.e_run IS NOT NULL) SELECT "Location", (b_run - e_run) AS improvement FROM combined ORDER BY improvement DESC LIMIT 20

Avg Sit Ups Improvement by Coach

How this was computed · 15 rows
