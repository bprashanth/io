Shuttle Run Improvement by Gender

How this was computed · 2 rows
SELECT endline.Gender, AVG(endline."Shuttle run sec") - AVG(baseline."Shuttle run sec") AS shuttle_diff FROM endline JOIN baseline ON endline."Child ID" = baseline."Child ID" GROUP BY 1 ORDER BY 2 DESC LIMIT 20
