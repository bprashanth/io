This dashboard provides a snapshot of the children's progress between the baseline and endline assessments. The total number of children participating is 200. The bar charts highlight the average improvement in shuttle run time and sit-ups, grouped by location and coach respectively. The top 10 shuttle run improvements are displayed in a table, showcasing the most significant gains. Further analysis could explore the factors contributing to these improvements, such as coaching styles or location-specific training programs.

Average Shuttle Run Improvement by Location

How this was computed · 20 rows
SELECT T1."Location", SUM(T2."Shuttle run sec" - T1."Shuttle run sec") AS shuttle_run_improvement FROM baseline T1 INNER JOIN endline T2 ON T1."Child ID" = T2."Child ID" GROUP BY 1 ORDER BY 2 DESC LIMIT 20

Average Sit Ups Improvement by Coach

How this was computed · 15 rows
SELECT T1."Coach", SUM(T2."Sit ups" - T1."Sit ups") AS sit_ups_improvement FROM baseline T1 INNER JOIN endline T2 ON T1."Child ID" = T2."Child ID" GROUP BY 1 ORDER BY 2 DESC LIMIT 20
