This dashboard tracks key metrics for school performance across 9,343 districts. The gender ratio shows 110 girls for every 100 boys in 2024, highlighting persistent gender gaps. Enrolment trends reveal 4,202 students grew by 4,202 between 2022 and 2024, with 46 schools showing the most significant increases. Infrastructure data exposes critical gaps: p5.non_functional_toilets schools lack functional girls' toilets, while p5.no_water_supply and p5.no_electricity schools face basic service deficiencies. Only 25% of schools meet minimum toilet standards, requiring urgent attention to improve learning environments.

How this was computed · 6 rows
WITH yearly_data AS (
  SELECT 'Girls' AS gender, "Girls 2022" AS count, '2022' AS year FROM "school_enrolment_by_year"
  UNION ALL
  SELECT 'Girls', "Girls 2023", '2023' FROM "school_enrolment_by_year"
  UNION ALL
  SELECT 'Girls', "Girls 2024", '2024' FROM "school_enrolment_by_year"
  UNION ALL
  SELECT 'Boys' AS gender, "Boys 2022" AS count, '2022' FROM "school_enrolment_by_year"
  UNION ALL
  SELECT 'Boys', "Boys 2023", '2023' FROM "school_enrolment_by_year"
  UNION ALL
  SELECT 'Boys', "Boys 2024", '2024' FROM "school_enrolment_by_year"
)
SELECT gender, year, SUM(count) AS total FROM yearly_data GROUP BY 1, 2 ORDER BY 2, 1

Top 10 schools by enrolment growth (2022-2024)

How this was computed · 10 rows
WITH growth_data AS (
  SELECT 
    "School Name", 
    "Block", 
    ("Girls 2024" + "Boys 2024") - ("Girls 2022" + "Boys 2022") AS growth
  FROM "school_enrolment_by_year"
)
SELECT 
  "School Name", 
  "Block", 
  growth
FROM growth_data
ORDER BY growth DESC
LIMIT 10
