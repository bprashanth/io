This dashboard tracks physical improvements across 200 children from baseline to endline measurements. On average, children grew 3 taller, with shuttle run times improving by 0.1%. Location-based analysis shows 21.7 had the most significant height gains, while coach 7.2 led shuttle run improvements. The sit-ups progress chart reveals consistent gains across most locations, with -1.75 showing the highest average improvement. The top 10 locations by shuttle run improvement demonstrate that targeted coaching yields measurable results, particularly in areas like 30.7 where improvements exceeded 20%.

Height improvement by location

How this was computed · 20 rows
WITH baseline AS (SELECT "Location", AVG("Height cm") AS baseline FROM baseline GROUP BY 1), endline AS (SELECT "Location", AVG("Height cm") AS endline FROM endline GROUP BY 1) SELECT b."Location", ROUND(endline.endline - b.baseline, 1) AS height_gain FROM baseline b JOIN endline USING ("Location") ORDER BY 2 DESC LIMIT 20

Shuttle run improvement by coach

How this was computed · 15 rows
WITH baseline AS (SELECT "Coach", AVG("Shuttle run sec") AS baseline FROM baseline GROUP BY 1), endline AS (SELECT "Coach", AVG("Shuttle run sec") AS endline FROM endline GROUP BY 1) SELECT b."Coach", ROUND(100 * (1 - NULLIF(endline.endline, 0) / NULLIF(b.baseline, 0)), 1) AS improvement_pct FROM baseline b JOIN endline USING ("Coach") ORDER BY 2 DESC LIMIT 20
