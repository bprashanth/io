Child Improvement by Location and Coach

Comparing baseline and endline metrics to show progress.

The dashboard presents two primary metrics of child improvement: average shuttle run time reduction and average increase in sit-ups. Panel p1 visualizes how different locations contributed to faster shuttle run times, with the most improvement highlighted at the top. Panel p2 shows which coaches were most effective in boosting sit-up counts across their groups. The table panels p3 and p4 list the top five locations and coaches, respectively, providing a quick reference for the most impactful areas. Observations should focus on the magnitude of improvement (6.3 and 11.09) and the consistency across locations and coaches, noting any outliers or patterns in the narrative.

Average Shuttle Run Improvement by Location

Showing the first 20 of 45 Location values.

How this was computed · 45 rows
SELECT b.Location, AVG(e."Shuttle run sec" - b."Shuttle run sec") AS avg_improvement FROM baseline b JOIN endline e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC

Average Sit Ups Improvement by Coach

How this was computed · 15 rows
SELECT b.Coach, AVG(e."Sit ups" - b."Sit ups") AS avg_improvement FROM baseline b JOIN endline e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC
