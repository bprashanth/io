Sit-ups Gain by Location

How this was computed · 15 rows
SELECT b."Location", AVG(e."Sit ups" - b."Sit ups") AS sit_ups_gain FROM "baseline" b JOIN "endline" e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC NULLS LAST LIMIT 15

Shuttle Run Improvement by Coach

How this was computed · 15 rows
SELECT b."Coach", AVG(b."Shuttle run sec" - e."Shuttle run sec") AS shuttle_improvement FROM "baseline" b JOIN "endline" e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC NULLS LAST LIMIT 15
