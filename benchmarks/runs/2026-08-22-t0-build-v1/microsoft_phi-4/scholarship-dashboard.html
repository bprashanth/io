This dashboard provides an overview of the scholarship applicants. The total number of applicants is 300. Applicants by Status

How this was computed · 5 rows
SELECT "Status", COUNT(*) AS count FROM scholarship_applicants GROUP BY 1 ORDER BY 2 DESC

Average Marks by Status

How this was computed · 5 rows
SELECT "Status", AVG("Marks %") AS avg_marks FROM scholarship_applicants GROUP BY 1 ORDER BY 2 DESC

Average Family Income by Status

How this was computed · 5 rows
SELECT "Status", AVG("Family Income") AS avg_income FROM scholarship_applicants GROUP BY 1 ORDER BY 2 DESC

Applicants by Taluka

How this was computed · 10 rows
SELECT "Taluka", COUNT(*) AS count FROM scholarship_applicants GROUP BY 1 ORDER BY 2 DESC LIMIT 10
