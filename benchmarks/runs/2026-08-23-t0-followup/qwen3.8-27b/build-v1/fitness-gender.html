Gender Parity in Fitness Improvement

Comparing baseline and endline performance metrics for boys and girls

Total Participants
200

This report examines whether boys and girls are improving at the same rate in physical fitness. We compare the average shuttle run times and sit-up counts from the baseline to the endline assessment.

The total number of participants tracked is 200. The bar charts show the average performance for each gender at both time points. A decrease in shuttle run time indicates improvement, while an increase in sit-ups indicates improvement.

The table below details the specific improvement metrics for each gender. The 'shuttle_improvement' column shows the reduction in time (positive is better), and 'situps_improvement' shows the increase in count (positive is better). By comparing these values, we can see if one gender is outpacing the other in specific areas.

Average Shuttle Run Time (sec)

How this was computed · 4 rows
SELECT "Gender", AVG("Shuttle run sec") AS avg_time FROM "baseline" GROUP BY 1 UNION ALL SELECT "Gender", AVG("Shuttle run sec") AS avg_time FROM "endline" GROUP BY 1

How this was computed · 2 rows
WITH b AS (SELECT "Gender", AVG("Shuttle run sec") AS base_shuttle, AVG("Sit ups") AS base_situps FROM "baseline" GROUP BY 1), e AS (SELECT "Gender", AVG("Shuttle run sec") AS end_shuttle, AVG("Sit ups") AS end_situps FROM "endline" GROUP BY 1) SELECT b."Gender" AS gender, b.base_shuttle, e.end_shuttle, (b.base_shuttle - e.end_shuttle) AS shuttle_improvement, b.base_situps, e.end_situps, (e.end_situps - b.base_situps) AS situps_improvement FROM b JOIN e ON b."Gender" = e."Gender" ORDER BY 1
