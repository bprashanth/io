Avg Shuttle Run Improvement by Location

How this was computed · 15 rows
SELECT b."Location" AS location, AVG(b."Shuttle run sec" - e."Shuttle run sec") AS avg_improvement FROM "baseline" b JOIN "endline" e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC LIMIT 15

Avg Sit-ups Improvement by Coach

How this was computed · 15 rows
SELECT b."Coach" AS coach, AVG(e."Sit ups" - b."Sit ups") AS avg_improvement FROM "baseline" b JOIN "endline" e ON b."Child ID" = e."Child ID" GROUP BY 1 ORDER BY 2 DESC LIMIT 15
