A "point" is a percentage point: the plain difference between the two rates (example: 74.0% − 66.0% = 8.0 points). Both districts rose over these two years; Nalanda was higher in both years, and Gaya's rate rose a little more. The data shows the change; it cannot show what caused it.

Why is Gaya below Nalanda?

This file cannot tell. It only records, per district and year, how many pregnancies were registered and how many completed 4 or more checkups. It has no information about health facilities, health workers, how far women travel, what services are offered, or how any programme was run. So it can show the gap (in 2023: Gaya 74.0%, Nalanda 80.0%), but it cannot explain it.

To investigate the reason you would need additional data, for example:

  • facility-level service data: how many facilities offer ANC in each district, opening hours, staff on duty;
  • health worker staffing and vacancy records by district;
  • records of actual programme activities, outreach sessions, and funding in each district;
  • surveys of women and families on access problems (distance, cost, timing, awareness).

None of these are in anc4_coverage.csv, so any explanation for the gap would be a guess.

How the rate is calculated

Coverage rate = (pregnancies with 4 or more ANC checkups completed) ÷ (registered pregnancies) × 100
  • anc4_completed = number of registered pregnancies in the district and year that completed 4 or more antenatal checkups.
  • pregnancies_registered = total number of pregnancies registered in the district and year (the denominator).

Source

  • File: anc4_coverage.csv. This page shows the 2021–2023 rows from it (15 rows); the file also contains 2020, which is not shown here.
  • Source field in the file, identical for every row: "synthetic Bihar ANC fixture" — this is sample/fixture data, not a real health record extract.
  • Columns used: district, year, pregnancies_registered, anc4_completed, source.
  • Geography: districts of Bihar, India. Years shown: 2021, 2022, 2023 (the file's full range is 2020–2023). Each district-year appears exactly once.

Because the source is a synthetic fixture, figures show how to read the table, not actual programme performance. Coverage rates describe a share of registered pregnancies; this data alone cannot explain why districts differ.
