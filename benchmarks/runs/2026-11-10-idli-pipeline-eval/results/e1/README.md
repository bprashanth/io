## Interpretation

The denominator is 62 file/kind combinations, spanning 27 distinct mistake kinds.
All real-kind detectors fire; individual heuristic limitations are stated in JSON
`note` fields. A kind surviving somewhere in the column does not prove preservation
of every planted instance. Empirical numeric ranges, sparse-row classification,
rare close spellings, and synthetic category substitutions are inherently ambiguous.
Count survival requires both matching and mismatching rows; the reports include both
shares so a column of entirely wrong counts cannot pass as preserved contrast.

V2 preserves tree count contrast exactly (37 matches, 3 mismatches). Household
counts retain the real residuals among the retained records (288 matches, 12
mismatches); the existing 300-row cap accounts for the changed denominator.
Blanks already survive per cell; numeric placeholders needed a V2-only read option
because pandas otherwise consumes literal NA text before faking.

The mandatory/optional template row is kept verbatim. The descriptive germination
row contains short non-imperative fragments and numbers, so it does not pass the
conservative template rule and remains altered. Preambles, merges, spacers, truncated
rows, date ordering, and arbitrary arithmetic rules remain outside these cheap fixes.
The tax date-order detector loses its baseline hit because V2 changes random-number
consumption; there is no date-order repair in the requested cheap fixes.
