# Benchmarks

This directory is the reproducible evidence for the NGO data-dashboard agent
comparison. Read [`DESIGN.md`](DESIGN.md) before adding cases or running models.

```text
benchmarks/
  DESIGN.md                 measured protocol and freeze points
  config/                   model ladder and scoring rules
  schemas/                  machine-readable case and run contracts
  cases/                    immutable inputs, prompts, provenance and oracles
  runners/                  agent/application/browser runner documentation
  scripts/                  environment, case and evidence utilities
  runs/                     raw per-run evidence, grouped by benchmark batch
  results/                  aggregate results derived from raw runs
```

## Evidence rule

Do not report a measured result only in prose. A reportable run contains the
case ID, exact messages, raw agent output, generated file hashes, browser
evidence, deterministic scores, visual review, versions, settings, time, and
usage/cost. See [`schemas/run-record.schema.json`](schemas/run-record.schema.json).

Large caches and model weights are not evidence and must not be checked in.
Small public inputs, generated sites, screenshots, downloads, and raw structured
transcripts should be retained. If an artifact is too large or cannot be
published, its manifest must say what is absent and why.

`smoke-001` verifies the harness end to end and is not included in headline
model results. The repository now also contains the frozen five-case
development screen, smaller-model futility evidence, and named alternative-
harness diagnostics. Holdout cases and repeated finalist runs have not yet
started.

The first paired development run was a calibration pilot and is deliberately
excluded from aggregates; see [the pilot findings](../docs/pilot-findings.md).
The content-addressed manifest for measured screening is generated by
`scripts/freeze_screening.py`. Screening v1 was invalidated when the shared
slim image lacked `ps`; the counted manifest is
`config/screening-freeze-v2.json`, and all v1 evidence remains explicitly
excluded.
