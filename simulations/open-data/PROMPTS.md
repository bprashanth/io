# open-data

## Survey Question

Can we make a simple public-style dashboard from programme reach and spending data?

## Data

`data/`

This folder has village reach, budget versus spend, and an annual summary. It does not have private names or phone numbers.

## Suggested Questions

1. Make a dashboard of programme reach by village and month.
2. Which villages are underperforming on children reached per session?
3. How does spending compare with budget by category?
4. Add a simple donor view with totals, trend, and one headline.

## Results

No fixed dashboard is required for comparison. This packet is mainly to check whether the tools avoid hiding harmless public-style data.
